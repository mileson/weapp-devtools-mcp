# v0.1.0

## Highlights

- First public release of WeApp DevTools MCP.
- Local WeChat Mini Program DevTools automation through MCP.
- Privacy-first defaults for screenshots, logs, tool results, and high-risk
  `wx` methods.
- Dependency audit passes with zero production vulnerabilities.

## Installation

```json
{
  "mcpServers": {
    "weapp-dev": {
      "command": "npx",
      "args": ["-y", "github:Mileson/weapp-devtools-mcp"],
      "env": {
        "WEAPP_WS_ENDPOINT": "ws://localhost:9420"
      }
    }
  }
}
```

## Verification

```bash
npm ci
npm run build
npm audit --omit=dev
```

## How To Use

Start WeChat DevTools automation on port `9420`, then call
`mp_ensureConnection` from your MCP client before using page or element tools.
