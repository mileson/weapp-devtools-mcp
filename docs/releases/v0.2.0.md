# v0.2.0

This release expands WeApp DevTools MCP into a fuller local DevTools control surface while keeping explicit user choice around high-risk actions.

## Added

- Tool profile controls with `WEAPP_TOOLS_PROFILE`, category switches, and per-tool allow/deny lists.
- Local network monitoring tools for `wx.request`, `wx.uploadFile`, and `wx.downloadFile`.
- `page_snapshot` for compact, minimal, or JSON page structure snapshots.
- `assert_element` for selector-based UI assertions.
- `mp_evaluate` for trusted Mini Program runtime evaluation.
- `mp_mockWx` and `mp_restoreWx` for local API mocking.
- `mp_runCli` for trusted local WeChat DevTools CLI commands.
- `mp_toolConfig` for inspecting the active profile and safety switches.

## Changed

- High-risk `wx` calls can now be allowed per call with `riskConsent=true`, through `WEAPP_ALLOW_HIGH_RISK_WX=true`, or through `WEAPP_ALLOWED_WX_METHODS`.
- Sensitive output redaction remains enabled by default across the new tools.

## Security

- Added explicit gates for evaluate, mock, restore, and CLI tools.
- Added `WEAPP_BLOCKED_WX_METHODS` for user-defined hard blocks.
