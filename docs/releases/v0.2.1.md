## Highlights

- Hardened transitive dependency pins for the public package release path.
- Synced README, Chinese README, and `.env.example` with the current launch and safety controls.
- Added a release handbook entry so public release notes stay aligned with the tagged version.

## Installation

Use directly from GitHub in an MCP client:

```json
{
  "mcpServers": {
    "weapp-dev": {
      "command": "npx",
      "args": ["-y", "github:Mileson/weapp-devtools-mcp"],
      "env": {
        "WEAPP_WS_ENDPOINT": "ws://localhost:9420"
      }
    }
  }
}
```

## Verification

```bash
npm ci
npm run build
npm audit --omit=dev
```

## How To Use

Start WeChat DevTools automation, point `WEAPP_WS_ENDPOINT` at the local
automation port, then call `mp_ensureConnection` before page, element, network,
runtime, or CLI tools.
